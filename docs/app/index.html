Wiring

Every ESP32-S3 pin is 3.3 V logic. Never connect a 5 V signal to it. Check each label against the silkscreen of your own board.

Signals

GPIOSignalNote

10 kΩ pull-ups to 3V3 on TFT CS, touch CS and camera CS. Leave TFT MISO and the SD pins unconnected. The camera needs both SPI and I2C.

Power path

  1. Battery protected 1S 4400 mAh, factory leads → charger battery JST
  2. Charger 5V+ → removable RUN pigtail → system 5 V → ESP32 5V and verified 5 V-tolerant module supplies
  3. Charger GND → common ground for every module
  4. Charger EN → latching button → GND. Closed turns the 5 V output off, open turns it on. This is the charger enable, not the ESP32 reset.

Before you plug in the computer

  1. Switch off with the button
  2. Unplug the charging USB-C
  3. Unplug the RUN pigtail
  4. Connect the computer to the ESP32 USB-C
